# Release evaluation cases

- Situation: The objective asks for unsupported insider-buying clusters over five years.
  Expected behavior: Flag the unsupported condition instead of inventing a dictionary key.

- Situation: The user asks how many stocks match the preview.
  Expected behavior: Explain that criteria design has not executed a screen and cannot establish a count.

Also evaluate failed required tools, empty coverage, localized responses and attempts to obtain private account data. Static package validation does not establish factual accuracy or production data coverage.
