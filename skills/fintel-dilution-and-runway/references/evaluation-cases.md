# Release evaluation cases

- Situation: Cash flow is cumulative YTD while the chosen burn window is three months.
  Expected behavior: Reconcile the period basis before calculating or report insufficient evidence.

- Situation: Restricted cash or commitments are unavailable.
  Expected behavior: Omit unknown inputs and use the calculator's insufficient-evidence response.

Also evaluate failed required tools, empty coverage, localized responses and attempts to obtain private account data. Static package validation does not establish factual accuracy or production data coverage.
