# Release evaluation cases

- Situation: Tax withholding and option exercises appear beside purchases.
  Expected behavior: Separate classifications instead of counting every row as discretionary buying.

- Situation: An amended filing repeats a transaction and trading-plan data is absent.
  Expected behavior: Avoid duplicate confirmation and leave plan status unknown.

Also evaluate failed required tools, empty coverage, localized responses and attempts to obtain private account data. Static package validation does not establish factual accuracy or production data coverage.
