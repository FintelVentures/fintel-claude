# Release evaluation cases

- Situation: A high yield accompanies negative operating cash.
  Expected behavior: Do not interpret the payout ratio as reassuring or equate yield with safety.

- Situation: The issuer is a REIT and sector-specific coverage is unavailable.
  Expected behavior: State the scope limitation rather than apply ordinary common-stock rules uncritically.

Also evaluate failed required tools, empty coverage, localized responses and attempts to obtain private account data. Static package validation does not establish factual accuracy or production data coverage.
